🔗 Integration Guide

How to Use Shared Assets

All HTML pages are now integrated with shared CSS and JavaScript utilities:


<link rel="stylesheet" href="css/styles.css">


<script src="js/utils.js"></script>

Available Helper Functions

  • showToast(message, duration) - Display notifications
  • showLoading() - Show loading spinner
  • navigateTo(page) - Navigate with smooth transition
  • saveData(key, value) - Store data in localStorage
  • getData(key, default) - Retrieve from localStorage
  • validatePhone(phone) - Validate Indian mobile number
  • formatDate(date) - Format dates in en-IN locale
